![# Portfolio cá nhân - Nguyễn Viết Tâm

Website giới thiệu bản thân được xây dựng bằng HTML và CSS, nhằm trình bày thông tin cá nhân, kỹ năng, mục tiêu học tập và các kênh liên hệ của tôi.

## 1. Giới thiệu dự án

Dự án này là một trang portfolio đơn giản nhưng hiện đại, dành cho sinh viên năm 3 ngành Công nghệ thông tin. Website giúp tôi giới thiệu:

- Thông tin cá nhân
- Mục tiêu nghề nghiệp
- Kỹ năng đang học và rèn luyện
- Các liên kết mạng xã hội / liên hệ

Giao diện được thiết kế theo phong cách tối giản, rõ ràng, dễ nhìn, phù hợp cho một website cá nhân.

## 2. Mục tiêu

- Tạo một không gian online để giới thiệu bản thân
- Thể hiện kỹ năng lập trình và phong cách thiết kế
- Tạo nền tảng để kết nối với người khác qua mạng xã hội hoặc GitHub
- Học tập và thực hành các kỹ năng frontend cơ bản như HTML, CSS, layout, responsive design

## 3. Công nghệ sử dụng

- HTML5: cấu trúc nội dung trang web
- CSS3: thiết kế giao diện, khoảng cách, màu sắc, layout
- JavaScript (nếu có bổ sung sau này): tương tác và hiệu ứng động
- Tải ảnh từ thư mục local `images/`

## 4. Cấu trúc thư mục

```bash
portfolio/
├── index.html      # Trang chính
├── style.css       # File CSS định dạng giao diện
├── readme.md       # Tài liệu mô tả dự án
├── image.png       # Hình ảnh sơ đồ hoặc minh họa
├── images/
│   ├── avatar.jpg
│   ├── 1.jpg
│   ├── 2.jpg
│   ├── 3.jpg
└── ...
```

## 5. Tính năng chính

- Header với menu điều hướng: Trang chủ, Giới thiệu, Kỹ năng, Liên hệ
- Phần giới thiệu bản thân với tên, ngành học và mục tiêu
- Hình ảnh cá nhân và banner đẹp mắt
- Phần "Khám phá thêm" hiển thị các mục thông tin quan trọng
- Phần kỹ năng với các thẻ kỹ năng như HTML, CSS, JavaScript, Teamwork, AI Training
- Nút liên hệ đến Facebook, Zalo và GitHub
- Thiết kế responsive, hiển thị tốt trên cả máy tính và điện thoại

## 6. Cách chạy website

Bạn có thể mở trực tiếp file `index.html` trên trình duyệt để xem website.

### Bước 1
Mở thư mục dự án.

### Bước 2
Nhấp đúp vào file `index.html` hoặc mở bằng trình duyệt.

### Bước 3
Website sẽ hiển thị giao diện portfolio cá nhân.

Nếu muốn chạy bằng live preview hoặc extension preview trong VS Code, bạn có thể dùng chức năng "Open with Live Server".
